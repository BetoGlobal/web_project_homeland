# Tripleten web_project_homeland

## Descripción

Este es el proyecto del sprint #5 llamado "Homeland" que presenta un catalogo de las ciudades de origen de los ingenieros en TripleTen.

## Tecnologias Usadas

- HTML5
- CSS3
- BEM
- Git/GitHub
- Google Fonts
